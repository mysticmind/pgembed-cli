Description:
  Remove cached versions (never ones in use)

  Examples:
    pgembed cache clean --keep-latest

Usage:
  pgembed cache clean [options]

Options:
  --keep-latest       Keep only the newest version of each major
  --version <SPEC>    Remove one version or major, for example 15 or 16.4.0
  --all               Remove everything that is not in use
  --dry-run           Only show what would be removed
  --cache-dir <PATH>  Cache folder for downloads and instances (default: PGEMBED_CACHE_DIR, else the
                      per-user cache folder)
  --maven-repo <URL>  Maven repository or mirror with the Postgres binaries (default: Maven Central,
                      or PGEMBED_MAVEN_REPO)
  --json              Machine-readable output
  --verbose           Log details to standard error
  -h, --help          Show help and usage information
