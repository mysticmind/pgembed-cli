DESCRIPTION:
Delete instances and their data

USAGE:
    pgembed rm [NAMES] [OPTIONS]

EXAMPLES:
    pgembed rm demo

ARGUMENTS:
    [NAMES]    Instance names; * and ? match several, for example ci-*

OPTIONS:
    -h, --help                Prints help information
        --cache-dir <PATH>    Cache folder for downloads and instances (default: PGEMBED_CACHE_DIR,
                              else the per-user cache folder)
        --maven-repo <URL>    Maven repository or mirror with the Postgres binaries (default: Maven
                              Central, or PGEMBED_MAVEN_REPO)
        --json                Machine-readable output
        --verbose             Log details to standard error
        --all                 Every instance
        --force               Stop a running instance first
    -y, --yes                 Delete without asking
